# RSN01

RSN01 is a React and TypeScript web project built with Vite and modern frontend tooling.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Lucide React
- Express

## Project Structure

```text
src/              Application source code
public/           Public assets
index.html        Application entry point
vite.config.ts    Vite configuration
.env.example      Environment variable template
```

## Getting Started

```bash
npm install
npm run dev
```

The development server is configured to run on port 3000.

## Build

```bash
npm run build
npm run preview
```

## Configuration

Use `.env.example` as the reference for local configuration. Never commit real credentials or API keys.

## Status

The repository is an active development project and can be further improved with project-specific documentation, automated testing, and CI checks.
